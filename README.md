# 50 sources de Java da CodeNomad Academy

Este repositório reúne 50 programas completos em Java, cada um num único arquivo, prontos para rodar e explicados onde importa. Ele serve para quem está aprendendo Java e quer ler código moderno de verdade (records, switch expressions, text blocks, sealed interfaces, streams, java.time, java.nio.file), e para quem já programa e quer uma calculadora, um validador, um organizador de pastas, um servidor HTTP ou um jogo de terminal sem instalar biblioteca nenhuma. Cada source faz uma coisa bem definida, valida a entrada, dá mensagens de erro claras e termina com três exercícios para você continuar. É um projeto da [CodeNomad Academy](https://codenomad.org), plataforma de autoestudo em desenvolvimento de software.

## Como rodar

Requisito: um JDK 17 ou mais novo, de qualquer distribuição. Nada mais. Nenhuma source usa pacote de fora: só os pacotes `java.*` e `javax.*` que vêm com o JDK.

Não precisa compilar antes. Desde o Java 11 o comando `java` aceita um arquivo `.java` direto: ele compila na memória e executa na hora. É esse o jeito de rodar todas as 50 sources.

Rodar uma source com argumentos reais:

```bash
java sources/01_calculadora_juros_compostos/CalculadoraJurosCompostos.java 1000 0,8 24 200
```

Rodar a demonstração de qualquer source:

```bash
java sources/01_calculadora_juros_compostos/CalculadoraJurosCompostos.java --demo
```

A flag `--demo` executa uma demonstração completa com dados de exemplo, sem pedir nada no teclado e sem acessar a internet. Ela termina sozinha em poucos segundos e é o jeito mais rápido de ver o que o programa faz antes de ler o código.

Sem argumento nenhum, o programa mostra o uso. Os jogos (46 a 50), sem argumentos, entram no modo interativo. Os caminhos nos exemplos partem da raiz do repositório.

Se preferir o caminho clássico, ele também funciona: `javac CalculadoraJurosCompostos.java` gera o `.class` na pasta e `java CalculadoraJurosCompostos --demo` executa. O [.gitignore](.gitignore) já ignora os `.class` para eles não irem parar no repositório.

Acentos no terminal: cada source redireciona a saída para UTF-8 logo no início do `main`. Se o seu terminal mostrar caracteres estranhos no Windows, rode `chcp 65001` antes, ou use um terminal que já fale UTF-8.

## Como este material é organizado

Um arquivo por programa. Cada source vive em `sources/NN_nome/NomeDaClasse.java`, em que `NN` é o número de 01 a 50 e a classe pública tem o mesmo nome do arquivo, em PascalCase, como o Java exige. Tudo o que o programa precisa está dentro dessa classe: records, enums, interfaces e classes aninhadas estáticas. Não há módulos compartilhados: você copia um arquivo e ele funciona sozinho.

Cabeçalho padrão. Todo arquivo começa com o mesmo bloco de comentário `/** ... */`, com cinco campos: "O que faz", "Como usar" (o comando real e o comando com `--demo`), "O que você aprende", "Requisitos" e a licença. Dá para saber se a source serve antes de rolar a tela.

Comentários onde importa. Os comentários estão nos pontos em que um aluno costuma tropeçar: por que dinheiro se conta em centavos inteiros e não em `double`, por que `SecureRandom` e não `Random` para senhas, por que `(baixo + alto) >>> 1` no lugar de `(baixo + alto) / 2`, por que `Files.walk` precisa de try-with-resources, por que um record serve de chave de `HashMap` sem escrever `equals` e `hashCode`. O resto do código fala por si.

Bloco "Para ir além". Cada arquivo termina com três exercícios sugeridos para você estender o programa com o que acabou de ler.

Só biblioteca padrão. Os 50 arquivos usam apenas o que vem com o JDK: `java.util`, `java.util.stream`, `java.time`, `java.nio.file`, `java.math`, `java.security`, `java.net` e `java.text`. Isso é de propósito: você aprende a linguagem, não um framework.

Java 17 de verdade. Os arquivos usam o que a linguagem ganhou até o Java 17 e nada além disso: records com construtor compacto, sealed interfaces, switch expressions com `yield`, text blocks, pattern matching com `instanceof`, `var` em variáveis locais e `HexFormat`. Tudo roda em modo source-file, sem `javac` separado.

Dois modos em toda source. Com argumentos, o programa faz o trabalho de verdade. Com `--demo`, ele mostra tudo o que sabe fazer sem depender de você. Erro de entrada vira uma mensagem que começa com `Erro:` e código de saída diferente de zero, nunca uma pilha de exceção.
